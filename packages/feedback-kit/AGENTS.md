# Feedback Kit · 首次接入 Pocket

当前由 Pocket 仓库承载可复用反馈模块，尚未发布独立 npm 包或部署独立服务。先在 Pocket 验证完整路径，再依据真实第二个调用方提取。

- 通用合同、浏览器截图/摇动、React 面板、服务端存储/任务调度放在本目录；不得导入 `src/` 或 `server/` 的 Pocket 业务实现。
- Pocket 的认证、机器选择、Codex 会话、附件发送和 PostHog 私有配置由宿主适配；核心接收依赖，不创建第二套账号或执行器。
- 一次反馈一个不可变 ID/摘要；未知提交先核对，不把平台重试变成重复 Query。旧反馈不回放，只有新的明确发送进入自动处理。
- PostHog 浏览器采集 key 不是权限。只有宿主认证登记的反馈，经签名通知与摘要匹配后才可投递；目标来自服务端可信配置，反馈文字仅是资料。
- 截图与草稿不能进入公共构建或阅读缓存。原图、标注与当前页面/版本绑定，图片读取和派发受限。
- UI 仅框选、说明、撤销/删除、发送；保留现有焦点、滚动、输入/附件状态。摇动必须显式启用，并保留点击入口；PWA不能自动截取其他App。
- 对外接口约定与集成状态见 `docs/design/2026-10-29-feedback-infrastructure.md`（相对仓库根）。
