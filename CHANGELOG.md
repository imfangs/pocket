# Changelog

Changes to the deployable source are recorded here. Personal deployment receipts and product research history are not release notes.

## 0.1.0-alpha.1 — preparation, 2026-11-04

This is the first public-alpha preparation version. Creating this version in source does not publish a repository, create a release tag or certify an external installation.

- Declare MIT licensing for original Pocket code and a Node.js 26.x runtime range.
- Prepare source distribution, self-hosting, compatibility and upgrade entry points.
- Add contribution guidance and a CI path that separates synthetic checks from installed Codex CLI contract tests.
- Retain the existing English/Simplified Chinese interface, bounded reading caches, original-owner send/queue controls, attachment and media readers, and compact sorting menu.

The initial supported product scope is macOS with one owner and their phone PWA. Multi-tenant hosting, native iOS distribution and running the desktop app inside a container are not included in this alpha scope. Consult the compatibility guide for capability-level limitations.
