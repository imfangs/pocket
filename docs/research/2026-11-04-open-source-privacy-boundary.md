# Pocket 开源隐私边界核验

日期：2026-11-04。范围：当前源树、可达 Git 历史中的已知私人标记、白名单源码导出、默认安装数据与浏览器存储、可选代理/遥测/反馈。未修改线上服务、私人配置或 Codex 原数据；未执行公开发布。

## 结论

默认安装的数据隔离方向正确：Pocket 数据在源码仓库外的 `~/Library/Application Support/CodexNavigator`，安装配置/日志在忽略的 `.local/pocket`，Codex 数据仍由 `~/.codex` 原会话拥有。浏览器另有阅读缓存及可选反馈草稿；这不是“所有私有数据只留在 Mac”。

**现有维护仓库及其历史不能直接公开。** 当前运维配置/文档和历史仍含个人部署域名、实际家目录及基础设施标识。应从已审查的白名单源码导出建立新的公开 Git 基线，保留原维护仓库为私有。没有证据表明本次调查之前已经将这些材料公开。

本轮确认并修复了一个具体导出缺口：旧导出会包含测试源码和合成机器配置中的真实个人部署域名。它们不是凭据，但不符合用户要求的公开隐私边界。现已统一换成保留同一语义的占位域名，生产生效配置保持。

## 数据离开设备的边界

- 手机或浏览器：`pocket-reading-cache-v1` 保存有限的会话/消息阅读投影，磁盘预算 30 MiB、期限七天；`feedback-kit-drafts-v1` 可保存未提交反馈文字/截图。本机站点偏好和阅读水位另有 localStorage。普通未发送 Query 在当前页内存保护，不属于持久阅读缓存。
- 浏览器退出：成功响应后尝试清除阅读/反馈缓存，存储失败不等于物理擦除成功。共享设备仍应使用浏览器站点数据管理。浏览器缓存和 Mac 数据均没有额外的应用级静态加密。
- 原模型提供方：通过 Codex 提交的内容按其模型/账号政策处理；Pocket 的本地数据目录不能消除这个边界。
- 自有 HTTPS/Cloudflare：中继经过的请求和响应可包含私有会话，TLS 是逐跳保护，没有额外的手机到 Mac 应用端到端加密。代理/中继运营者属于信任边界。
- 遥测：通用导出关闭 analytics，项目键/允许来源为空。现有私人部署可能启用；本地录制设置遮罩所有文字/输入且不录制网络头/体和控制台，未认证第三方全部采集行为。
- 用户主动反馈：可将说明、URL、来源会话 ID、版本/视口/数量发给配置的 PostHog；截图本机保存，发送到选定开发会话时进入其附件/模型处理路径。跨机反馈中继也会传所选报告/图片。默认无有效私人配置则关闭。
- 推送：按用户订阅调用浏览器推送提供商；加密载荷包含泛化状态、会话/机器和事件标识，不包含回复正文。外部提供商仍可观察投递元数据。

公开给使用者的数据表及操作入口以根目录 `PRIVACY.md` 为权威，本记录是维护者调查证据，不进入公开源码白名单。

## 明确的剩余边界

已知标记扫描不是通用凭据探测，也不证明任意命名的个人文件、压缩内容、所有历史秘密和不可达对象均安全。新用户未配置或未登记的任意域名/秘密无法自动识别；公开提交仍应本机审查 staged diff，未知值用私人 deny 文件登记。

`.gitignore` 不是权限机制。用户把任意名称的数据目录放进源码并强制提交时，工具不能承诺 Git 永远无法上传；默认选择、检查命令和白名单发布是防误操作层。真实新 Mac/手机安装、远程路由与使用、公开资产和完整许可/发布流程验收仍沿原 Alpha 发布门槛处理。
