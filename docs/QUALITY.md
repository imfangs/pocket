# 手机远控持续打磨

2026-09-28 方帅要求持续打磨远控，让它顺滑。目标入口是 iPhone 添加到主屏幕后的 x.fangs.cc；返回手势是从左边缘向右滑。

## 每次接续

先读 CURRENT.md 和最新用户反馈，核对工作区及线上版本。选择一个有真实摩擦或明显验证缺口的完整流程，取得基线，完成最小改动、相关回归和真实回读，再发布。没有值得改的事项时保持现状。每日两次的同任务 heartbeat 只在有明确进展、重要验证结果或需要用户处理时通知。

持续改善现有读取、发送、恢复和移动交互；新建任务、另起 app-server、自动审批和扩大访问权限仍按 AGENTS.md 的边界处理。任务数据、历史和草稿不进入公开构建、Git 或第三方模型。每次发布保持可回退并保留源码/部署身份。

UI 组件引入先读 [AI Elements 适用性评估](research/2026-09-28-ai-elements-fit.md)：研究阶段建议先隔离验证 MessageResponse；本轮视觉打磨采用 Radix Popover + Sonner，保留现有 Markdown / 输入 / 队列，具体取舍见 [视觉系统](design/2026-09-28-pocket-polish.md)。

调研候选的执行边界见 AGENTS.md；两项已完成外部调研的采用判断见 [2026-09-29 调研输入](research/2026-09-29-external-research-intake.md)。研究基线中的停止、异步问题和恢复已有增量实现；下一次大规模补功能前，先比较官方 Remote 的实际账号可用性与现有任务覆盖，不能仅凭官方说明判定替代效果。

## 已建立的验收基线

- 上下文压缩：原 owner 受控压缩从 237904 tokens 降到 6898，事件 completed、原始 compacted 记录确认，0 工具调用，归档恢复。`.local/qa/compact-live.json`；接口返回 accepted 不能代替完成。


- 队列与直接发送：公网受控任务实测运行中添加/编辑/删除；直接发送留在同一 turn，排队消息在 completed 后开启下一 turn，准确回显、0 工具调用、取消消息未执行、原归档已恢复。证据 `.local/qa/queue-live.json`。Pocket 与桌面待发列表独立；PWA 真机交互仍待验。


- 受控回显：公网 messages → 现有桌面 owner → 模型 → 公网 history，准确 requestId 与指定回复均回读；回合 completed，仅 userMessage/agentMessage，0 工具调用；测试前后的归档状态一致。证据 `.local/qa/remote-echo.json`。
- 切换/离线：本次登录内最多保留 10 个已读任务及阅读位置。断网后切回仍有 48 条消息，scrollTop=9812 不变，发送禁用；联网后状态恢复，新增消息不抢阅读位置。证据 `.local/qa/feed-browser.json`。
- 读取调度：单路请求；运行中完成读取后 2 秒、空闲 8 秒再读；后台停止，前台/联网/pageshow 立即重读，18 秒超时后有界退避。缓存内容不会直接恢复发送许可。
- 本机服务重启前后分组/备注哈希一致。证据 `.local/qa/feed-restart-baseline.json`、`feed-restart-after.json`。
- 键盘与手势、Markdown、原 ID 与认证的既有证据见 QA.md。自动测试、桌面浏览器、iOS 模拟器、PWA 真机、长期使用效果分别表述。

## 受控发送验收

只有发送/桥接相关改动或链路异常需要时才运行，不把每日回显变成任务污染。默认真实验证保持只读或操作可恢复的 Pocket 元数据。

需要真实模型回显时，使用 `.local/qa/remote-echo.json` 已记录的相关验收对象，先核对它没有运行/待审批或新的人类工作。临时恢复原归档仅用于该次测试，完成后恢复。文本只要求回复唯一标记，明确禁止调用工具、修改文件、发布文档或外发消息。提交前落盘 requestId，重复运行先检查回执与原历史；未知结果不重发。不以接收回执代替模型完成，也不把单次 API 回显升级为 PWA 真机发送或长期可靠性验收。
