## 服务与拒绝路径

FBT local 管理常驻进程和 HTTPS，域名解析到 127.0.0.1 与 ::1。实际域名同源 POST `/api/sync` 返回 200；跨站 Origin 返回 403；直接后端伪造 Host 返回 403。源异常使用合成输入验证，没有移走真实 Codex 文件。
