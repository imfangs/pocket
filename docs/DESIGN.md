# 界面约定

方向：安静、可读的本机任务书架，沿用 Codex 的文字密度，增加真正的分组和接续详情。桌面三栏（导航 228 / 灵活任务列表 / 详情 340），浅灰绿导航底、白主面、深墨绿选中态、细分隔线；中文系统字体，正文 14–15px，任务标题 15px，页面标题 26px。图标使用 18px、1.7 stroke 的线性 SVG。没有装饰图片和指标卡。

导航：全部任务、原版置顶、正在推进、稍后继续、留作参考、最近打开、原版归档；我的分组为可折叠树，来源项目独立过滤。列表包含标题、来源、接续说明摘要和最近时间；选中后在详情编辑意图、分组、备注与可选回顾日期，主按钮在 Codex 打开。搜索固定在列表上方。空态解释当前筛选，不虚构任务。

窄屏折为列表和详情两层，导航以抽屉开启。控件具备焦点、键盘进入与 Esc 返回；减少动态时关闭过渡。状态字段和说明与真实 API 结果一致。

概念生成偏差：当前会话没有可调用的内置 image_gen；用户没有要求切到付费 API 生图。此工具以用户提供的原侧栏截图和以上可实现规范作为视觉依据，直接通过浏览器截图迭代，不把未生成的图片称作已批准设计。验证记录须诚实说明这一偏差。
