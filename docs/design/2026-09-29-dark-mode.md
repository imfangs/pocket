# 亮色、暗色与系统主题

2026-09-29 用户明确要求暗色模式。本轮只实现明确需求及压缩可用性反馈；外部调研候选继续按 AGENTS.md 的讨论边界处理。

三选项为亮色/暗色/系统，默认跟随系统，选择存在本设备 localStorage 的 pocket.theme；跨标签页同步，退出登录仍保留。初始化 public/theme.js 在 React 之前设置主题，避免保存为暗色的页面先呈现亮色。浏览器无法访问存储时仍允许本标签页切换。

| 角色 | 暗色值 |
| --- | --- |
| 主背景 | #18181e |
| 侧栏 | #14141a |
| 输入、队列、问题卡 | #22222b |
| 正文 / 次级文字 | #eceaf2 / #b2adbf |
| 紫色强调 / 选中背景 | #b9a6ff / #302941 |

颜色覆盖集中于 theme.css；不改变 fixed inspector 的祖先变换、键盘 visualViewport 或发送/停止状态机。主题组件使用外部状态订阅，切换只改变 CSS 与偏好，不重建 App。主操作和停止按钮使用反色前景；状态颜色保留运行绿、审批黄、错误红。主题入口在侧栏底部独立成行，触屏按钮至少 44px，登录页也可选择。

主题同步 color-scheme 与 theme-color；离线页复用公开初始化脚本。SW v3 只增加缓存公开 theme.js，私人 API、目录、历史与草稿不进入离线缓存。导航强制向网络验证，失败使用公开离线页。安装时的原生启动画面与状态栏表现仍需 PWA 真机验证。

验证覆盖主题恢复、存储受限、系统变化/手动覆盖、主要文字对比度 >=4.5、320/390/1280px 布局、草稿与阅读位置、队列/审批/问答/弹窗以及真实停止隔离后端后的暗色离线页。证据见 .local/qa/theme/。
