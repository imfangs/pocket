## 用户看到的行为

文件引用和普通本地文件 Markdown 链接共用轻量文件入口。2026-10-28新增文本页内预览：支持的文本文件显示文件名与“查看”，其余文件保持下载。只有点击才读取文件，失败原地解释并允许重试；正文流式更新不会重建链接组件、中断读取或清掉错误。离开详情会中止尚未完成的读取。未登记或无法开放的本地引用显示名称和“文件保存在电脑上”，不暴露一段组件代码。

2026-10-29新增[视频播放](2026-10-29-message-video.md)：已登记的MP4/M4V/MOV/WebM文件引用可原生播放，Markdown图片语法中的视频也共用该通道。视频按需流式传输，不套用文本Blob预览；普通文件的20MiB下载与文本1MiB预览边界保持。

已有会话链接、代码批注、后续建议、批注编号和定时任务摘要保留。未知 `codex-*` 组件展示已有标题/正文和“此内容请在 Codex 查看”，不猜测其交互；流式未闭合组件先显示载入提示。用户原话、代码块、行内代码和转义示例保持字面量，组件本身不触发发送、执行或归档。复制与屏幕正文使用相同的展示转换。

## 文件数据通道

- `shared/codex-directives.mjs` 共用属性、代码/HTML保护和路径解析。拒绝重复属性、不完整引用、转义冒号、未知组件里的路径、URL/控制字符。组件属性里的示例链接不另行签发文件能力。真正 Markdown 本地链接支持一次 URI 解码，引用组件的路径保留字面。
- `MessageFiles` 仅从服务端返回的完整、可见 assistant 正文登记引用；用户内容、analysis 和已截断正文不签发文件能力。原消息不修改，额外返回 `files[原引用路径] = {name, url}`。
- URL 为 `/api/tasks/:threadId/files/:HMAC`，绑定当前会话和 cwd，无任意路径 GET。每次历史最多32个、进程最多256个、有效期1小时，解析缓存128项；正文超过128Ki字符不解析。
- 点击时重验当前会话目录、真实路径、普通文件、20MiB大小上限和读取前后路径/文件身份；符号链接逃逸、替换、变动或缺失返回安全错误。HTTP文件响应始终按附件返回；客户端只在以下文本边界内读取并展示，HTML/SVG不作为文档或图像执行。
- 保留认证、Host/Origin/CSRF相关访问边界、no-store、nosniff、same-origin和沙箱CSP。前端核对当前thread和机器身份，拒绝伪造相对、绝对与内部render-token链接；下载流同样限制20MiB。
- 内容能力不是执行能力，不进入发送账本或共享桌面状态。切机沿用原机器路由和生命周期，不能跨机复用文件引用。

共享解析代码计入前端版本哈希，修改共享组件也会正确触发安全更新。暂不提供任意目录浏览、未引用文件读取、内嵌 Office 编辑器或全量附件同步。

## 2026-10-28 文本页内预览

后续：2026-11-07新增[HTML静态页面与嵌图预览](2026-11-07-html-file-preview.md)，默认页面/可切源码、原件下载保持。下述HTML按字面显示记录保留当时实现，现行HTML行为以新契约为准；SVG和其他代码仍按字面显示。

用户要求在Pocket直接阅读md、txt等文件，不必下载后切换手机App。只修改前端，复用原文件GET及签名校验，后台无需升级。

- `messageFileText.ts` 按文件名选择支持的Markdown、普通文本与常见源码；UTF-8或带BOM的UTF-16严格解码。非法编码、二进制控制字符和超过1MiB的内容不做预览，保留原20MiB下载能力。响应头、流式累加及解码前各自检查，预览限额不能提高原下载上限。
- 手机使用全屏阅读窗，桌面限制最大宽度；顶部固定文件名、下载与带文字的关闭按钮，正文独立滚动。关闭或Escape回到原文件入口并保持会话阅读位置；modal遮挡遵循现有阅读可见性事件。
- md/markdown安全排版；普通文本、HTML、SVG和代码按字面显示。文件中的Codex指令不转换为动作，不复用其本地引用，不加载图片，不执行raw HTML；外链仅允许http/https/mailto并隔离新窗口。
- 每次打开才读取，30秒超时或网络失败在阅读窗原地重试；关闭、换文件、换会话或换机器取消读取并释放预览内容，不持久保存文件正文。大文本只作轻量失败说明，不截断后冒充全文。
- 同一次打开成功后，下载复用当前正在阅读的已校验Blob，保存相同字节且不再次GET；关闭后重开重新读取。超限、无法解码或尚未完成预览时，下载仍走原有独立请求。此缓存只属于当前预览，不借缓存扩展文件、路径、机器或执行权限。
- 正文区显式标记为不可采集/文本遮罩，避免新增文件预览进入录制正文。没有新增文件上传、发送、会话修改或遥测事件。
