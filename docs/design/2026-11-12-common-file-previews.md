# 常见文件链接直接预览

普通图片文件链接原先只提供下载，即使原件已登记、可读且是有效JPEG，也没有进入图片查看器。本轮复用原文件能力增加预览，保持原件下载，并将同一条消息的图片、图片文件卡及图片附件接到同一图库。归档入口同时移入会话分类区，底部设置保留独立图标和文字入口，原筛选及归档行为不变。

## 显示与界限

| 文件 | 点击后的行为 | 界限 |
| --- | --- | --- |
| PNG/JPG/JPEG/GIF/WebP | 紧凑文件卡打开既有大图，参与同消息左右切换 | 8MiB、扩展与签名匹配；普通下载保持 |
| Markdown、文本、代码、JSON、CSV等 | 既有页内正文／源码阅读 | 1MiB文本读取；正文不继承会话能力 |
| HTML | 既有页面与源码切换 | 原独立交互沙箱与资源边界保持 |
| PDF | 按页阅读、继续显示更多 | 20MiB、50页起步、最多200页；附近最多5个画布，单画布4Mi像素 |
| SVG | 静态图片预览 | 1MiB、DOMPurify与内部引用过滤，不加入栅格图后端通道 |
| DOCX | 标题、段落、列表、表格和有界嵌图 | 内容预览；复杂版式不作Word完整排版承诺 |
| XLSX | 工作表切换与保存的结果；无结果时显示公式字面 | 不计算公式；有界工作表、行列与单元格 |
| PPTX | 幻灯片内容卡、文字、表格和有界图片 | 明确内容预览，布局可能不同 |
| ZIP | 文件目录与大小列表 | 不自动展开嵌套压缩包；保留原件下载 |
| WAV/MP3/M4A/AAC/OGG/FLAC | 原生音频控件 | 受控文件流、512MiB、Range/IfRange/HEAD；具体编码由浏览器验证 |
| MP4/MOV/M4V/WebM | 既有原生视频 | 原播放与原件下载能力保持 |
| 旧Office或专有二进制 | 下载原件 | 不把未知数据伪装成已可读 |

文件卡默认不读取私人原件或自动铺开大图，用户打开后才读取。预览支持原件下载：已有Blob时复用同一份字节，关闭后释放；没有Blob的音视频仍走原件读取。语言切换不重新打开文档，标题和关闭控件固定，正文沿用私有录制屏蔽与阅读遮挡标记；焦点、草稿、IME及聊天滚动根保持。

## 权限与资源

服务端`files/<key>/image`及`files/<key>/audio`只接受原文件登记能力，保持thread、cwd、有效期、realpath与inode核对，不接受客户端磁盘路径。图片扩展、签名、8MiB与权限错误保持，普通下载仍20MiB。音视频共用原Range、背压、16槽、取消及停机释放逻辑；短EOF统一409，不能因抽取函数漏带错误helper退化成404。

浏览器图库只新增精确的`files/<key>/image`地址，裸files、普通外站、query或跨thread地址不能借此进入图片组。SVG、PDF和Office各走受控内容展示，不继承消息文件、问题或执行权限。原「文稿」目录的macOS访问拒绝仍需本人允许实际后台程序，新增预览不等于该目录已恢复。

PDF采用React-PDF/PDF.js，静态SVG采用DOMPurify，Office采用Mammoth、ExcelJS、fast-xml-parser和有界fflate。库仅用于前端构建与惰性内容解析；Mac API的324项生产依赖图保持。新增依赖和既有构建工具进行了定向补丁核对，当前npm audit为0；不以此声称全部内容风险消失。PDF的字体/CMap/解码资产走同源白名单，开发与构建两条入口一致；没有放宽全站CSP或启用PDF脚本、表单、外站资源。

Office解析在单独的可取消Worker中，12秒期限；20MiB输入、2000ZIP条目、40MiB实际扩展、8MiB单条目、XML深度／节点／总量及输出预算。ZIP实际解压长度与CRC核对后形成净化解析包，原Blob下载不变。XLSX预处理阻止mergeCells、cols、definedNames及稀疏地址的隐式全表分配；Office解析器的本地XML关系目标同样进入DTD与深度检查，不能凭扩展或TargetMode跳过。图片累计16Mi像素、正文和表格有输出上限，超出时标明内容不完整并保留原件。

## 验证与接续

证据分开保存：实际指定JPEG的登记／原件200及字节哈希；旧版缺预览和图库的负例；正式构建上的同消息切换、权限、关闭、旧图事件、下载、PDF/SVG/音频与Office流程；库与HTTP协议、独立资源审查和发布回读。工具或夹具误判单独记录，不作为产品修复：WebKit指针焦点归还、内部Blob测试路由、旧SVG/PDF下载断言及图标SVG计数都有前后依据。
