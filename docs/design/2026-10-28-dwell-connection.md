# 停留五秒后的提前连接

2026-10-28。欧吉安选择「停留5秒后连接」，开始输入仍立即连接；同时确认跳过有待发消息的会话。相比打开即连接，这能过滤快速浏览，又把可能的连接等待提前到阅读阶段。

## 触发与取消

- 当前会话连续可见、在线满5秒时，最多被动尝试一次。切换、页面隐藏、离线和原生弹层/阅读浮层覆盖会取消计时；重新可见后重新计5秒。普通消息更新不重置计时。
- 原生输入手势保留独立的尝试机会，并取消本次浏览剩余的被动计时。程序聚焦、恢复草稿不会被当成输入意图；输入事件仍等传播完成后发起连接，保护首字符与IME。
- 被动连接正在进行时，真实输入可以升级同一后台操作，并立即触发共享的单次打开；不会先等原owner查询结束，也不会重复打开。跳过/失败不消耗真实输入的机会。
- 已连接、归档、缺失、范围外、分隔符、管理/停止/压缩/型号操作、未知请求和待发队列等阻塞时跳过。前端用于避免无用请求，服务端在开始、异步读取之后和真正打开之前再次检查。

## 接口与原会话

`POST /api/open/:id` 的空body/`{}`保留既有显式连接；`{intent:"reading"}`走被动read-first。先查原owner，已有可用owner时直接复用；需要时仍调用现有 `open codex://threads/<id>`，可能唤起Codex或改变Mac当前显示的会话，不能称作纯网络预热。

初始跳过返回顶层`status:"skipped"`及当前thread/connection，不记录额外打开时间。进行中跳过或静默失败返回带原请求身份的连接终态`skipped`；显式连接/新提交可将同一在途entry提升为普通流程。被动成功不主动唤醒队列，既有全局队列行为保持；因此必须先检查队列，不能只关闭一次唤醒就宣称没有发送影响。

连接本身不调用start/steer，不直接消耗模型Token；开销来自Mac载入会话、短期Python进程、IPC历史快照的读取/序列化及HTTP流量。没有另建模型执行器或每会话永久隧道。原生会话可能继续驻留，Pocket没有离开详情即卸载它的能力；已经发出的打开操作也不能随着前端退出可靠撤回。未实测具体内存、耗时或电量，不给出估算MB当作事实。

## 验证

覆盖5秒边界、前后台/离线/弹层、一次性与输入抢先、被动在途升级、跳过/失败恢复，以及队列和管理状态在异步读取中变化。使用合成原生接口和浏览器，不通过真实连接去测开销或触发用户队列。实际发布身份与设备验证范围见[CURRENT](../../CURRENT.md)。
