# 独立优先关注与输入意图

2026-10-15。方帅要求将Pocket排序标记与Codex置顶分开，精简常用文案，主动输入时预连接，并把近期消息时间改为相对表述。发布身份回 CURRENT。

## 两个独立标记

- Pocket叫“优先关注 / 取消关注”，使用红星；Codex置顶为只读紫图钉。两者可并列，不改变原会话的时间、归档、模型或权限；优先关注也不是通知订阅。
- `pocketPriority`只取私人表`pin_overrides.pinned===1`，缺省false；`codexPinned`只取来源原生pin。Rank分别加90、60分，双标记共150分，其他因子保持，没有硬置顶层。取消关注只撤下90分。
- 旧true自然成为优先关注，旧false只表示无优先。曾被false遮住的Codex图钉重新独立显示；原记录不删除，不做物理迁移。
- 新`POST /api/tasks/:id/priority`只接受`{priority:boolean}`并返回完整会话；重复设置幂等，缺省false不建行、不备份。旧`/pin`及`pinned/pinnedOrder/pinSource`保留旧覆盖行为兼容旧PWA。
- version 1备份继续用pins字段。两状态共用单调`pinRevision`；存在Pocket override时，原生pin变化也推进revision。成功/迟到回复整组更新；旧或半套投影不能给已知状态套上新版本。新客户端不向旧混合接口回退写入。
- 左划仍为84px蓝色区域，桌面/键盘用星标；换位动效只跟随已确认的Pocket值，Codex状态变化不会误确认关注操作。

## 输入时预连接

浏览、恢复草稿、程序聚焦都不连接。当前文本框的真实点击、Tab到达、输入、粘贴或IME才表达意图；选择附件也可预连接。本次视图只自动尝试一次，请求合并；失败后打字不循环重连，切换后的旧结果不串入另一会话。

复用`/api/open/:id`和既有后台连接流程，quiet模式不弹重复toast。预连接不发送正文，不改变原模型/cwd/权限。右下只有一个主操作：有内容直接发送/入队；空输入失败时同一按钮变“重试连接”；空输入连接中显示spinner。未知发送仍按原requestId核对，不重放POST。

离线、兼容性、归档/缺失、管理/审批/压缩/停止、未知提交等阻塞时不自动连接。范围外或分隔符记录也不自动预连，这不改写既有手动发送契约。

## 文案与时间

界面统一用“会话”，常用状态收敛为“未连接 / 连接中 / 已发送”。删除重复“原任务”“原文已保留”等说明，保留失败、暂停、未知和核对的必要区别。历史正文原文不做替换；内部身份与回执继续保留。

消息右下角一周内显示“刚刚 / N分钟前 / N小时前 / N天前”，更早显示日期时间，跨年带年份；完整时间仍在datetime、title与无障碍说明里。无效时间不显示，未来时间不伪装成刚刚。全页只有一个前台分钟时钟，只更新时间组件，不重渲染正文或参与Rank。
