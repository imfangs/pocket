# Pocket 整体视觉重整

2026-10-19。方帅反馈“手搓感很强”“越改越粗糙”，明确授权按上一轮建议完成整体优化。本轮以整屏完成度和同场景对照为目标，不以引入组件库或测试通过代替审美验收。

## 范围和方向

覆盖列表、会话详情、新建三条核心路径，以及菜单、设置、问题/审批、队列、登录、启动和连接失败。保留原导航维度、关注/置顶区别、用户要求的输入边界，以及原会话、队列、未知回执、草稿、键盘、阅读位置和关闭保护。没有新增用户可见的说明区、管理入口或机器标识。

视觉采用中性slate灰、白色内容面板与indigo主操作；颜色与主次层级统一，中文正文/标签/辅助文字分级。具体参考是 [Radix Themes 的预设组件体系](https://www.radix-ui.com/themes/docs/overview/getting-started)及[主题与tokens机制](https://www.radix-ui.com/themes/docs/theme/overview)。Apple/Linear的层级与控件秩序作为设计方向，不宣称复刻其当前界面或提取了其像素参数。

## 实现归属

- `design-tokens.css`：字号角色、间距、圆角、主操作和语义色。辅助文字维持4.5对比阈值；第一轮发现light muted在浅底仅4.33，已加深修正。
- `styles.css` / `pwa.css`：保留结构、滚动、可见性、视口/安全区和平台行为，撤掉旧视觉声明。触摸端文本输入最小16px仍归平台层：它防止iOS自动缩放，是交互约束，不能当成普通视觉样式删除。
- `polish.css`：重新组织完整视觉层，统一列表密度、阅读、编辑器、控件、浮层、表单和访问页；删除旧theme.css，避免同一状态在多层里拼接。
- `ui/PocketTheme.tsx` / `Button.tsx` / `IconButton.tsx`：Radix Themes3.3.0薄封装，透传原生ref、aria、disabled与事件；默认type=button，真正表单提交显式submit。颜色偏好仍由原theme.js持有，Portal保持原DOM。
- 原`@radix-ui/react-popover`1.1.15及直接依赖锁定保持；不切换现有上下文浮层控制器、native dialog控制器或AutoTextarea节点。
- 发送确认/队列和列表状态从同一语义色阶派生。红色Pocket关注、紫色Codex置顶仍独立。
- 公开壳配色与字体跟随同一方向；静态离线页/Service Worker匹配升级为v11，不改只缓存公开壳的边界。

MIT许可随公开构建携带。完整官方Themes CSS使主样式达到约749KB、gzip93KB；包没有可直接使用的独立按钮预编译CSS，强拆会破坏尺寸/主题/loading。暂保留官方入口，不自建上游编译分叉，复查条件是有实际加载延迟或官方提供稳定按需入口。评估位于本轮QA的radix-css-assessment.md。此取舍不代表已测真机网络性能。

## 控件几何的后续反馈

Radix ghost不仅决定底色，也可能带负外边距。10-19主题分段、10-20详情返回按钮和10-22消息复制按钮分别出现命中区交叠或整区横滚。后续复用这类控件时，同验实际命中边界与父级scrollWidth/clientWidth；溢出即使只有2px也会影响导航手势。按布局局部消除不需要的负margin，保留既有触控尺寸，不用全局隐藏滚动条掩盖几何问题。复制按钮的因果复现与修复见[横滚与返回冲突](2026-10-15-motion-implementation.md#2026-10-22-主消息横滚与返回冲突)。

## 验证与接续

全部脚本、截图、原始回执、固定构建在 `.local/qa/visual-renewal-2026-10-19/`；`capture.mjs`与`regression.mjs`复用同一份样本，只替换构建。默认严格合成API，不发送、压缩、停止或修改真实会话。

最终候选build `7f3c17b57603b60a1b471c02df7ddffa1238e17ffd6f0299c210b10594f98d74` 已完成：1047项完整测试、构建、20张同条件截图/25项结构检查、70项双浏览器流程、15项输入字段检查与4项代表回读。前一候选另完成VV-only键盘/offsetTop/关闭重开、秘密输入16px及v11缓存边界验证；最终候选只修基础input选择器特异性，相关代表路径再次通过。两项P2均闭合，代码复审无剩余P1/P2。

第二轮视觉评审认可了整体一致性与四处修正，只保留登录口令行“框中框”一项。根因是默认input的多个:not选择器特异性高于组合控件的内层透明样式；现将基础规则改为:where，保持默认输入边界且允许组合字段覆盖。最终浅深受控局部回读确认口令行仅有一条边界、底色一致、两侧图标保留；搜索、普通query、秘密字段和原生select也分别复验。完整视觉意见在visual-final.md；最终用户对照图为release-comparison.jpg。

实际iPhone主屏幕/系统键盘手感不能由桌面模拟替代。当前视觉取舍已经过两轮独立评审和有据修正，交付后由真实使用继续检验。发布身份按下方记录和CURRENT核对；两机API与Codex无需重启。
