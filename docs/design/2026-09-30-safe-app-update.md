# Pocket 内的版本更新

2026-09-30，接续持续打磨现有体验。已知摩擦：前端发布后，打开中的 PWA 仍运行旧 JavaScript，过去只能让用户彻底关闭重开。静态 sw.js 不随每个前端构建变化，不能把 Service Worker ready 当作已更新。

## 行为与范围

- 任务列表顶部只在发现不同构建时出现“Pocket 有新版本 / 更新”。启动、回前台和联网恢复检查公开元数据，前台定期检查；后台不轮询。检测不会刷新、发送 query 或操作原任务。
- 用户明确点击后，先检查未完成输入/操作，再核对新版资源；不会记住一次点击，在用户以后完成输入时自动刷新。
- 保护跨任务普通草稿、空白输入、待核对 requestId、空文本的队列编辑、问题答案（含 secret）、整理/分组/备份修改、登录/通知/审批等在途流程。同步 getter 读取最新值，异步 hold 跨组件卸载保持到操作结束。
- 网络检查结束后再查一次保护条件，覆盖用户在等待期间开始输入的情况。当前没有需要保护的内容才刷新，并用现有 task 参数回到当时选择的任务。
- 不持久化草稿、问题答案、密码或历史，不修改原任务权限、发送账本或重放未知请求。
- 无 requestId 的旧问题草稿，仅当缓存里有明确 desktop 来源和显式当前问题数组、且原 key 已结束时不再阻止更新；没有缓存、回退历史、缺少数组或未知提交均保留保护。此判断不删除或改写 Map。

这项入口要先加载一次包含它的新版本，才会为后续版本提供提示。本轮首次启用仍需重开原来的旧页面。

## 版本与部署一致性

构建摘要只读取显式前端输入（src、public、入口、依赖锁和构建配置），不读取 .local、环境变量、会话或凭据。公开 pocket-version.json 只有摘要和构建出的 JS/CSS 路径，Cache-Control 为 no-store；HTML 同时带 pocket-build meta。

更新依次核验：新版 manifest → 每个 JS/CSS 的 HEAD 状态及类型 → 将要打开的入口 HTML 的 build ID → 再读 manifest 确认没有切换版本 → 再检查输入/操作 → 刷新。资源路径仅接受同源 assets 下的 JS/CSS，最多32项；HTML 回退、旧入口、无效元数据、网络失败或中途版本变化都保留当前页面，允许之后显式重试。

覆盖的是前端程序和样式的切换。Service Worker 对固定路径公开离线壳（theme.js、startup.css、图标）的既有缓存策略未调整；不声称已清理浏览器全部缓存或验证了 iPhone 后台更新。资源核验与真正导航之间仍有很短的网络竞态窗口，不能代替长期真实设备反馈。

## 验证

Browser plugin not available，使用既有 Playwright。两份实际 Vite 构建分别嵌入旧/新 build ID，隔离服务在页面打开后切换文件，验证真实 reload 后的 meta 和脚本发生变化。

| 检查 | 结果 |
| --- | --- |
| 单元与全量检查 | 最终188项通过，生产构建通过 |
| 手机390px | 隐藏任务的草稿阻止更新，草稿完整保留；清空后显式更新加载新版且提示消失 |
| 桌面1280px | 整理修改、secret 回答、问题选项、空待发编辑均阻止更新；完成后更新并恢复当前任务 |
| 网络等待 | 检查开始后新写的草稿仍能阻止刷新，之后清空不会自动更新 |
| 混合部署 | JS 路径返回 HTML、manifest/chunks 已新但入口仍旧，两种情况都不刷新；恢复后显式重试成功 |
| 旧问题 | 明确结束且无提交记录的问题草稿不永久锁住更新；不删除正文 |
| 视觉 | 轻量浅紫提示条与现有风格一致，更新按钮44px，手机列表与桌面详情保持可读；阻止原因放在更新条内部，不覆盖返回按钮 |
| 执行边界 | 合成验收不调用模型；只有测试队列的本地编辑/取消操作。正式站点验收仍只读或输入后清空草稿 |

默认无限制文件并发下，已有300ms桥接进程启动测试两次在发出 preflight 前超时，得到保守 unknown；其间独立重跑曾通过188项，说明原默认并发的稳定性不足。现将 npm test 限为4个文件工作进程，保留发送实现、超时预算和所有断言。首个浏览器脚本重复使用已取消编辑的合成队列时中止，补充每次初始化临时测试数据后重新验证；不将测试数据漂移记作产品缺陷。

公网联调进一步发现更新失败 toast 会覆盖手机返回按钮，指针停留又使提示不消失。已改为提示条内部说明，沿同一交互复测；不修改全局 toast 行为。公网脚本也改用原任务 ID 导航，不假定该任务必在当前筛选列表内。
