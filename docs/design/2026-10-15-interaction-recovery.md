## 行为契约

| 场景 | 当前处理 |

| 忽略问题与丢弃答案 | 忽略保留答案，“丢弃草稿”明确清除选项/自填两个模式；在途、accepted待同步和unknown不可丢弃。已忽略且没有草稿/未决请求的问题不再让普通输入区保持展开。 |
| 新建读取工作目录失败 | 15秒有界超时、失败原地“重新读取”、联网后一次补读；同时请求合并，迟到/取消结果不覆盖新结果。Query、标题、有效目录/项目保留，重试不重复读取剪贴板或自动创建。 |
| 离线误选附件 | 明确本地 queued/failed 且未上传、未核对、未待删除的附件可移除；unknown、已上传、提交中和管理受限状态保留保护。离线重试上传仍禁用。 |
| 离线页重新连接 | 空相对链接重新请求当前 URL，保留 task 参数。当时公开壳v6升至v7；随后[离线布局](2026-10-15-offline-layout.md)更新为v9并加入页面版本核验。私人API和正文缓存规则保持。 |

| 归档会话继续输入 | 同一主按钮为“取消归档”（10-18统一文案），显式点击走现有生命周期回执与等待流程；聚焦/输入不恢复，成功后保留 Query，仍由用户点击发送。 |

| 触控细节 | 粗指针设备的导航/对话框关闭、活动过滤、管理和关闭确认控件至少44px高；关闭目标44×44px。图标不变，手机对话框头部总高保持。 |

## 实现与边界

- `listInteraction.ts`把按压到合成click的持有/释放封装在一个绑定里。拖动、指针取消、blur、页面隐藏与销毁均释放监听/几何；保留已离开当前目录的行只为短暂占位，激活时仍核对最新成员资格。排序公式不变，不能为了稳定触摸恢复硬置顶层。
- `creationOptions.ts`仅负责读取生命周期，不发创建请求。`NewConversationDialog`仍拥有选择和草稿，目录准备与输入可以并行。
- 回答草稿清理通过同一 question presentation store 通知普通输入区重新判断阅读态；未改变持久化字段或向 Codex 写入“已回答”。
- Outbox 放弃修改不需要服务端写入；保存/恢复继续沿用 expectedRevision、队列暂停和未知请求核对规则。
- 归档恢复从 Conversation 传到 Inspector 的现有 onArchive；没有新增生命周期接口。恢复期间阻止重复提交与更新，并保留当前 Query；跨视图迟到结果不写回新视图。
- 本轮没有服务端协议或数据表改动，发布无需重启 Pocket API、Codex 或连接器。
